# Mamba / Selective SSMs vs Transformers (Self-Attention): Mechanism-Level Trade-offs (theory and empirical analyses, 2023 to Oct 2026)

Scope note: this file covers only the core mechanism-level comparison of the two model families. Hybrid architectures (LLM, general vision, image restoration), the LF-SR challenges, and training-budget questions are covered in other notes. Tags used throughout: **[NLP]** = shown in language/synthetic-sequence settings; **[Vision]** = shown on images; **[Theory]** = formal result. Year = first arXiv/venue year.

Access note: arxiv.org, openreview.net and most publisher hosts were blocked from this research container. Claims were checked through search-engine extracts of the primary papers, official GitHub READMEs (fetched directly), and author blogs. Where a number comes only from a secondary summary, it is flagged as such.

## 1. Complexity and efficiency: linear scan vs quadratic attention, recurrent inference, wall-clock crossover, Mamba-1 scan vs Mamba-2 SSD

### Takeaway
In asymptotic terms Mamba is O(L) time and O(1) state at inference, while attention is O(L²) time with an O(L) KV cache. In wall-clock terms, though, the published kernel crossover against FlashAttention-2 is about **2K tokens** for both the Mamba-1 selective scan and the Mamba-2 SSD kernel (A100, single layer). Below that, attention is competitive or faster, and a whole Mamba-2 model is not necessarily faster to *train* than a Transformer at 2K. The large practical wins are in **autoregressive decoding throughput (no KV cache)** and in **very long sequences or high resolution** (e.g., about 6K image tokens in Vim).

### Cited Findings
- **[NLP, 2023] Mamba-1 core idea.** "Mamba: Linear-Time Sequence Modeling with Selective State Spaces," Gu & Dao, COLM 2024. SSM parameters (Δ, B, C) become functions of the input ("selection"), so the model can selectively propagate or forget information. This breaks the time-invariance that allowed S4 to be computed as a convolution, so the authors use a hardware-aware parallel scan (kernel fusion, keeping the expanded state in SRAM, recomputation in backward) — [arXiv 2312.00752](https://arxiv.org/abs/2312.00752)
- **[NLP, 2023] Mamba-1 kernel crossover.** "Our efficient SSM scan is faster than the best attention implementation that we know of (FlashAttention-2) beyond sequence length 2K." The scan is also 20 to 40× faster than a standard PyTorch scan. Benchmark: A100 80GB PCIe, batch 1, model dim 1024, state dim N=16, sequence length swept from 512 — [arXiv 2312.00752, Sec. 4.5 / App. E.5](https://arxiv.org/abs/2312.00752)
- **[NLP, 2023] Inference throughput.** Mamba achieves **4 to 5× higher inference (generation) throughput** than a Transformer of similar size, because it has no KV cache and can therefore use much larger batches. The 20 to 40× figure that circulates in blogs refers to the PyTorch-scan baseline, not to FlashAttention — [arXiv 2312.00752](https://arxiv.org/abs/2312.00752). Secondary source misreporting this: [HackerNoon summary](https://hackernoon.com/lite/how-mambas-design-makes-ai-up-to-40x-faster)
- **[NLP, 2023] Quality at scale.** Per the Mamba abstract, Mamba-3B outperforms Transformers of the same size and matches Transformers twice its size in pretraining and downstream evaluation (Pile-scale, about 300B tokens) — [arXiv 2312.00752](https://arxiv.org/abs/2312.00752)
- **[NLP, 2024] Why Mamba-1 was limited to small states.** Tri Dao's Mamba-2 blog explains that the Mamba-1 scan did not use tensor cores, so it was "limited to small state expansion (typically N=16)." The H100 offers 989 TFLOPS of BF16 matmul but only 67 TFLOPS of FP32 non-matmul arithmetic, and "one of our primary goals with Mamba-2 is to leverage tensor cores" — [Mamba-2 blog Part III](https://tridao.me/blog/2024/mamba2-part3-algorithm/); [Part IV (systems)](https://tridao.me/blog/2024/mamba2-part4-systems/)
- **[NLP, 2024] Mamba-2 / SSD speed.** "Transformers are SSMs: Generalized Models and Efficient Algorithms Through Structured State Space Duality," Dao & Gu, ICML 2024. Restricting A to a scalar times identity turns the SSM into a structured (semiseparable) matrix multiplication computable by block-wise matmuls. The SSD layer is **2 to 8× faster than Mamba-1's fused selective scan** (core-layer microbenchmark, A100, state size 64, sequence lengths 512 to 512K). It is also **faster than FlashAttention-2 starting at sequence length 2K**. The paper cautions that a whole Mamba-2 model "might not be as efficient to train as Transformer at short sequence length (e.g. at 2K)", because at equal parameter count it replaces MLP layers with SSD layers — [arXiv 2405.21060](https://arxiv.org/abs/2405.21060); measurement-condition summary in [Tri Dao blog Part IV](https://tridao.me/blog/2024/mamba2-part4-systems/)
- **[NLP, 2024] Larger states in Mamba-2.** Because SSD uses matmuls, Mamba-2 commonly runs with d_state 64 to 256 versus 16 in Mamba-1. This range comes from a secondary article; the primary blog only states the N=16 limitation of Mamba-1 — [towardsai summary via search](https://towardsai.com/?p=51859); [Dao blog Part III](https://tridao.me/blog/2024/mamba2-part3-algorithm/)
- **[NLP, 2026] Mamba-3 is "inference-first".** "Mamba-3: Improved Sequence Modeling using State Space Principles," Lahoti, Li, Chen, Wang, Bick, Kolter, Dao, Gu; ICLR 2026. It adds (i) exponential-trapezoidal discretization, (ii) a complex-valued state update shown to be equivalent to a data-dependent rotary embedding, and (iii) a MIMO formulation that "raises expressivity without increasing state size" and improves decode hardware utilization. The official repo exposes `is_mimo`/`mimo_rank` options — [arXiv 2603.15569](https://arxiv.org/abs/2603.15569); [state-spaces/mamba README](https://github.com/state-spaces/mamba); [Tri Dao blog, Mamba-3 Part 2](https://tridao.me/blog/2026/mamba3-part2/). Press coverage claims about 7× faster long-context inference than Transformers and "2× smaller states". These are secondary and unverified against the paper's tables — [lilting.ch](https://lilting.ch/en/articles/mamba-3-ssm-inference-latency); [MarkTechPost](https://www.marktechpost.com/2026/03/18/meet-mamba-3-a-new-state-space-model-frontier-with-2x-smaller-states-and-enhanced-mimo-decoding-hardware-efficiency/)
- **[NLP, 2024] Recall–throughput Pareto frontier.** Based (sliding-window attention with window about 64, plus global Taylor-feature linear attention) reaches **up to 24× higher generation throughput than FlashAttention-2** (1.3B params, generating 1024 tokens, batch 128). The authors frame efficient architectures as points on a recall-vs-memory (state size) Pareto frontier — [arXiv 2402.18668](https://arxiv.org/abs/2402.18668); [ICML 2024 PMLR](https://proceedings.mlr.press/v235/arora24a.html); [Together AI blog](https://together.ai/blog/based)
- **[Vision, 2024] Vim efficiency is resolution-dependent.** Vision Mamba (Vim), Zhu et al., ICML 2024: Vim is **2.8× faster than DeiT and saves 86.8% GPU memory** for batch feature extraction at **1248×1248 (6084 tokens)**. The advantage comes from linear time and linear memory and grows with resolution — [arXiv 2401.09417](https://arxiv.org/abs/2401.09417); [Vim README](https://github.com/hustvl/Vim)
- **[Vision, 2024] MambaOut FLOP threshold.** MambaOut (Yu & Wang, CVPR 2025) derives that attention's quadratic FLOP term exceeds its linear term when **L > 6D** (L = tokens, D = channels). This gives thresholds of τ = 2304 for ViT-S (D=384) and 4608 for ViT-B (D=768). ImageNet at 224² gives 196 tokens, far below the threshold. COCO detection and ADE20K segmentation (512×2048) give about 4K tokens, so they are long-sequence tasks — [arXiv 2405.07992](https://arxiv.org/abs/2405.07992); [CVPR 2025 paper](https://openaccess.thecvf.com/content/CVPR2025/papers/Yu_MambaOut_Do_We_Really_Need_Mamba_for_Vision_CVPR_2025_paper.pdf); FLOP-counting tutorial linked from [MambaOut README](https://github.com/yuweihao/MambaOut)
- **[Vision, 2024] Recurrent scans are slow in practice at moderate L.** MLLA/MILA (Han et al., NeurIPS 2024) reports that its parallel linear attention gives "significantly faster inference speeds compared to vision Mamba models," because Mamba's recurrent scan is not parallelizable the way linear attention is — [MLLA README](https://github.com/LeapLabTHU/MLLA); [arXiv 2405.16605](https://arxiv.org/abs/2405.16605)
- **[NLP, 2025] Throughput caveat in a non-generative setting.** In document reranking, Mamba models are competitive in quality "but also have a lower training throughput than efficient Transformer implementations such as flash attention" — [State Space Models are Strong Text Rerankers, RepL4NLP 2025](https://aclanthology.org/2025.repl4nlp-1.12.pdf)

### Inferences
- Asymptotic advantage does not equal wall-clock advantage. For one-shot (non-autoregressive) processing of about 1K to 2K tokens, FlashAttention is at least as fast as a selective scan. Mamba's structural advantages are (a) no KV cache during generation and (b) sequences well beyond about 2K to 4K tokens, or high-resolution images where an L² attention map does not fit in memory.
- In VMamba-style vision blocks (4-direction cross-scan, K=4), scan cost is multiplied by the number of directions, which pushes the practical crossover point higher still. Mamba-1-style kernels (N=16, no tensor cores) are the slowest per FLOP. SSD (Mamba-2) or chunked linear attention recovers matmul efficiency.
- **LFTransMamba-specific (from repo inspection, `models/LFTransMamba.py`):** the model uses C=64 channels, d_state=16, angular resolution 5×5, and 32×32 LR training patches (`lfsr.py`). Each cascade has VSSBlock (3 global self-attention TransBlocks via `F.scaled_dot_product_attention` over each SAI's 32×32 = 1024 tokens, then a 4-direction SS2D), VLSSBlock (3D scan), and LFSSBlock (4D scan, 25×1024 = 25,600 tokens per LF patch). With D=64, MambaOut's threshold is 6D = 384 tokens. Per-view spatial sequences (1024) are moderately "long" in FLOP terms but sit below the ~2K wall-clock crossover, so FlashAttention is appropriate there. The joint 4D sequence (25,600 tokens) is where the linear scan clearly wins, since attention would need 25,600² ≈ 6.6×10⁸ pairwise scores per head. This division of labor is consistent with the analyses above.

### Gaps
- No primary-source measurement was found of the scan-vs-FlashAttention crossover for **vision-shaped workloads** (large batch × short sequence, 4-direction scans, D=64). The 2K figure is for batch 1, D=1024 language-style kernels.
- Mamba-3's exact speed tables could not be read directly (arXiv blocked); only secondary summaries were available.
- Low-resolution Vim-vs-DeiT timings (e.g., 224 to 512 px) were not retrieved; only the 1248² headline.

## 2. Expressivity and capability limits of SSMs: copying, associative recall, in-context retrieval, fixed-state compression

### Takeaway
The fixed-size recurrent state is a lossy compression of the past. Attention keeps a lossless KV cache and can do exact, content-addressed lookup at any distance. Multiple independent lines of work (theory plus synthetic plus pretrained LLMs, 2023 to 2025) show that SSMs/Mamba lag attention on **copying, multi-query associative recall, phonebook-style lookup, few-shot ICL (5-shot MMLU), and in-context retrieval**. The gap scales with how much context must be retrieved relative to state size. Adding even a small amount of attention largely closes it.

### Cited Findings
- **[Theory+NLP, 2024] Copying.** "Repeat After Me: Transformers are Better than State Space Models at Copying," Jelassi, Brandfonbrener, Kakade, Malach; ICML 2024. The authors prove that a **2-layer Transformer can copy strings of exponential length**, while generalized SSMs (any fixed-size-state model) are fundamentally limited by their latent state. On synthetic copying, Transformers are more sample-efficient and generalize better to longer inputs. Per the paper, Mamba needs about 10× more data than Transformers even for short strings, and LSTMs about 100× — [arXiv 2402.01032](https://arxiv.org/abs/2402.01032); [PMLR v235](https://proceedings.mlr.press/v235/jelassi24a.html); [Kempner blog](https://kempnerinstitute.harvard.edu/research/deeper-learning/repeat-after-me-transformers-are-better-than-state-space-models-at-copying/)
- **[NLP, 2024] Pretrained models.** In the same paper, pretrained Pythia (410M to 2.8B) "dramatically outperform" same-size Mamba models (all trained on the Pile) at copying and at **phone-book lookup**, evaluated 1-shot. Secondary summaries report that Pythia-410M beats Mamba-2.8B once the phone book is long enough; check the paper's figure for exact values — [arXiv 2402.01032](https://arxiv.org/abs/2402.01032); [Liner summary](https://liner.com/review/repeat-after-me-transformers-are-better-than-state-space-models)
- **[NLP, 2023] Associative recall explains most of the perplexity gap.** "Zoology: Measuring and Improving Recall in Efficient Language Models," Arora et al., ICLR 2024. Across 17 pretrained attention and gated-convolution models (H3, Hyena, RWKV, RetNet-style), gated-convolution models trail attention by up to 2.1 perplexity on the Pile, and **82% of that gap is explained by associative recall** of earlier-mentioned tokens. A **70M attention model beats a 1.4B gated-convolution model** on AR. The paper introduces **MQAR** (multi-query associative recall) and proves that gated convolutions need model dimension scaling with sequence length to solve it. Hybrids with input-dependent sparse attention close **97.4%** of the gap — [arXiv 2312.04927](https://arxiv.org/abs/2312.04927); [ICLR 2024 PDF](https://proceedings.iclr.cc/paper_files/paper/2024/file/448fc91f669c15d10364ee01d512cc10-Paper-Conference.pdf); [Hazy Research blog](https://hazyresearch.stanford.edu/blog/2023-12-11-zoology1-analysis)
- **[NLP, 2024] Mamba on recall-intensive tasks.** Based (Arora et al., ICML 2024) beats Mamba by **10.36 accuracy points** on recall-intensive downstream tasks in the published version (6.22 in arXiv v1). The Zoology/Based repo notes that "state size is a proxy for model efficiency" and that MQAR is "useful but simplistic" — [arXiv 2402.18668](https://arxiv.org/abs/2402.18668); [Hazy Research blog](https://hazyresearch.stanford.edu/blog/2024-03-03-based); [Zoology README](https://github.com/HazyResearch/zoology)
- **[Theory+NLP, 2024] In-context retrieval, even with chain-of-thought.** "RNNs are not Transformers (Yet): The Key Bottleneck on In-context Retrieval," Wen, Dang, Lyu; ICLR 2025. CoT improves RNNs but does not close the gap. The bottleneck is in-context retrieval: the authors prove that RNNs (including SSMs) with sublinear state cannot solve **associative recall** or **"is this graph a tree"**, which Transformers solve easily. Adding retrieval-augmentation or **a single Transformer layer** lets the RNN solve all polynomial-time problems with CoT — [arXiv 2402.18510](https://arxiv.org/abs/2402.18510); [ICLR 2025](https://proceedings.iclr.cc/paper_files/paper/2025/hash/79dc391a2c1067e9ac2b764e31a60377-Abstract-Conference.html)
- **[NLP, 2024] ICL task suite.** "Can Mamba Learn How to Learn? A Comparative Study on In-Context Learning Tasks," Park et al., ICML 2024. SSMs match Transformers on standard regression ICL and outperform them on sparse parity, but fall short on non-standard retrieval. A hybrid (MambaFormer) does well on both — [arXiv 2402.04248](https://arxiv.org/abs/2402.04248); [PMLR v235](https://proceedings.mlr.press/v235/park24j.html)
- **[NLP, 2024] 8B-scale controlled study.** "An Empirical Study of Mamba-based Language Models," Waleffe et al. (NVIDIA). 8B Mamba, Mamba-2, and Transformer models were trained on identical data up to 3.5T tokens. Pure Mamba and Mamba-2 "lag behind Transformer models on tasks which require strong copying or in-context learning abilities (e.g., five-shot MMLU, Phonebook Lookup) or long-context reasoning." An 8B hybrid (43% Mamba-2, 7% self-attention, 50% MLP layers) beats the Transformer on all 12 standard tasks (+2.65 points average) and is *predicted* to be up to 8× faster at generation — [arXiv 2406.07887](https://arxiv.org/abs/2406.07887); [NVIDIA Research](https://research.nvidia.com/publication/2024-06_empirical-study-mamba-based-language-models)
- **[NLP, 2025] Mechanistic explanation.** "Understanding the Skill Gap in Recurrent Language Models: The Role of the Gather-and-Aggregate Mechanism," Bick, Xing, Gu; ICML 2025. Both Transformers and SSMs implement retrieval via a few "Gather" and "Aggregate" heads. Disabling one such head in a pruned Llama-3.1-8B drops MMLU answer-letter retrieval from **66% to 25%**. In SSMs these heads show **smoother attention patterns instead of the sharp transitions** that G&A requires. Pretrained hybrids delegate the Aggregate role to attention layers, and replacing one G&A head in a pretrained SSM with attention boosts retrieval — [arXiv 2504.18574](https://arxiv.org/abs/2504.18574); [PMLR v267](https://proceedings.mlr.press/v267/bick25a.html)
- **[Theory, 2025] State must grow with stored entries.** Zhan et al. (NeurIPS 2025, HAX) prove that pure SSMs cannot solve multi-query *joint* recall unless state size grows linearly with the number of entries, and propose adding context-dependent sparse attention — [arXiv 2507.00449](https://arxiv.org/abs/2507.00449)
- **[NLP, 2024] State capacity is finite but scales with state size.** "Stuffed Mamba" (Chen et al., Tsinghua, 2024; latest version Jan 2026, retitled "Oversized States Lead to the Inability to Forget") finds that passkey-retrieval capacity of the recurrent state scales **exponentially with state size**. A Mamba-2 370M reaches near-perfect passkey retrieval at 256K context — [arXiv 2410.07145](https://arxiv.org/abs/2410.07145)
- **[Vision/Concept, 2024] Memory view.** MambaOut gives a memory view of the same trade-off: causal attention's KV memory is lossless but its cost grows with length, while an RNN-like model compresses the past into a fixed-size hidden state that is "inherently lossy" and "cannot directly compete with the lossless memory capacity of attention," though merging cost stays constant — [MambaOut README Fig. 2](https://github.com/yuweihao/MambaOut); [arXiv 2405.07992](https://arxiv.org/abs/2405.07992)
- **[Survey, 2025]** SSMs are competitive with Transformers and more efficient in specific long-context regimes, while "attention retains an advantage on tasks dominated by exact retrieval and associative recall" — [arXiv 2503.18970](https://arxiv.org/abs/2503.18970)

### Inferences
- Mechanism: Mamba's per-channel decay (Δ·A) plus input-dependent B, C lets it *choose* what to write. Mamba-1 shows this beats LTI SSMs on selective copying and induction heads. However, it still writes into about d_inner × N numbers. When the task requires retrieving one of many arbitrary key-value pairs (MQAR, phonebook, few-shot exemplars), information-theoretic capacity binds. Attention's softmax over a growing cache gives sharp, content-addressed selection, which Bick et al. show is precisely what SSM "attention" patterns lack.
- For image SR, the analogue of "recall" is non-local self-similarity: copying exact high-frequency texture from a distant patch or another view. Attention's lossless cache is better suited to this. Mamba's compressed state is better suited to smooth, decaying, structured aggregation.
- LFTransMamba's SSM state is small (N=16, d_inner = 64 × ssm_ratio 1). This strengthens the case that its attention blocks carry the exact-correspondence role and the SSM carries cheap long-range aggregation, consistent with Waleffe/Bick/Zoology. This is an inference from the LLM literature, not a measured result on LF data.

### Gaps
- Exact per-task phonebook numbers in Waleffe et al. and the exact copying curves in Jelassi et al. could not be read (arXiv blocked).
- I found **no paper measuring "recall"-type failure modes of Mamba directly in image restoration or SR** (e.g., exact texture copying across distant regions). The vision evidence is indirect (Section 5).

## 3. Where SSMs are better or different: state tracking, length extrapolation, recency/decay inductive bias, smooth long-range dependence

### Takeaway
SSMs are *not* universally weaker. On formal-language tasks they model star-free/flip-flop-type state tracking and bounded hierarchical structure, with length generalization where Transformers struggle. They also learn sparse parity better in ICL. Mamba-1 extrapolates induction-head retrieval about 4000× beyond its training length. However, standard Mamba (non-negative real diagonal transitions) **cannot do parity/modular counting** and is in TC⁰ like Transformers, so its "state" advantage is partly illusory. Fixes are negative eigenvalues (Grazzi et al.), complex/rotational states (Mamba-3), or non-diagonal transitions. Length extrapolation is also fragile in practice: the ERF is bounded by training length, and state collapse occurs.

### Cited Findings
- **[Theory+NLP, 2024] Mamba is no better than Transformers at state tracking.** "The Illusion of State in State-Space Models," Merrill, Petty, Sabharwal; ICML 2024. Linear SSMs, including S4 and Mamba, are in **L-uniform TC⁰**, the same class as Transformers. They therefore cannot solve inherently sequential state tracking such as **permutation composition (S5 word problems)**, tracking chess moves in certain notations, evaluating code, or tracking entities in long narratives. Experiments confirm S4 and Mamba struggle. A minimal extension (input-dependent, non-diagonal transitions) restores the ability — [arXiv 2404.08819](https://arxiv.org/abs/2404.08819); [ICML 2024 poster](https://icml.cc/virtual/2024/poster/34075)
- **[Theory, 2024] Circuit-complexity bound.** "The Computational Limits of State-Space Models and Mamba via the Lens of Circuit Complexity" (Chen et al., 2024) places poly-precision, constant-depth SSMs/Mamba in DLOGTIME-uniform TC⁰, implying they cannot solve problems like arithmetic/Boolean formula evaluation or permutation composition unless TC⁰ = NC¹ — [arXiv 2412.06148](https://arxiv.org/abs/2412.06148)
- **[Theory+NLP, 2024] Distinct strengths on formal languages.** "The Expressive Capacity of State Space Models: A Formal Language Perspective," Sarrof, Veitsman, Hahn; NeurIPS 2024:
  - SSMs with non-negative transitions can predictively model a regular language at finite precision **iff it is star-free**.
  - A two-layer SSM models **Flip-Flop** at arbitrary lengths, with length-generalizing solutions where Transformers struggle.
  - SSMs model **bounded hierarchical structure** with optimal memory without simulating a stack.
  - **PARITY/modular counting is impossible** for current Mamba-style SSMs because of non-negative gates.
  - The authors verify these results empirically on Mamba.
  — [arXiv 2405.17394](https://arxiv.org/abs/2405.17394); [NeurIPS 2024](https://proceedings.neurips.cc/paper_files/paper/2024/hash/485e0981e81766248b61fd1ec43c118f-Abstract.html)
- **[Theory+NLP, 2024/25] Negative eigenvalues fix parity.** "Unlocking State-Tracking in Linear RNNs Through Negative Eigenvalues," Grazzi, Siems et al., ICLR 2025. Diagonal transitions with eigenvalues in [0,1] (as in Mamba) cannot solve parity at finite precision. Extending the range to **[-1, 1]** lets Mamba and DeltaNet solve parity and improves state tracking. Products of generalized Householder matrices can learn any regular language. Models pretrain stably at 1.3B — [arXiv 2411.12537](https://arxiv.org/abs/2411.12537); [ICLR 2025](https://iclr.cc/virtual/2025/poster/29442)
- **[NLP, 2026] Complex states for state tracking.** Mamba-3 uses a complex-valued state update (equivalent to data-dependent RoPE) and states that it "overcomes the lack of state-tracking ability common in many current linear models." At 1.5B it reportedly improves average downstream accuracy by +0.6 pts over Gated DeltaNet, with MIMO adding another +1.2 pts (figures from search extract of the paper; not verified in tables) — [arXiv 2603.15569](https://arxiv.org/abs/2603.15569)
- **[NLP, 2024] Sparse parity in ICL.** Mamba outperforms Transformers on sparse parity in-context learning, and MambaFormer learns it with Mamba-like sample complexity — [arXiv 2402.04248](https://arxiv.org/abs/2402.04248)
- **[NLP, 2023] Selection enables extrapolation on simple retrieval.** In the Mamba-1 paper, LTI SSMs fail Selective Copying while selective SSMs solve it. On **induction heads**, Mamba trained at length 256 generalizes perfectly to about 1M tokens (about 4000×), whereas attention variants with standard positional encodings fail beyond about 2× training length — [arXiv 2312.00752](https://arxiv.org/abs/2312.00752)
- **[NLP, 2024] But practical extrapolation is limited.** "DeciMamba: Exploring the Length Extrapolation Potential of Mamba," Ben-Kish et al., ICLR 2025. Although Mamba's recurrent memory is unbounded in theory, its **effective receptive field is limited by the training context length**. DeciMamba (token decimation inside S6, training-free) extrapolates to contexts reported as 25× longer than training in v1 — [arXiv 2406.14528](https://arxiv.org/abs/2406.14528); [DeciMamba README](https://github.com/assafbk/DeciMamba)
- **[NLP, 2024] State collapse.** "Stuffed Mamba" identifies **state collapse**: severe degradation beyond the training length, attributed to the state being *over-parameterized* for the training length, so the model never learns to forget. The minimum training length needed to learn forgetting scales **linearly with state size**. Their mitigations let Mamba-2 process more than 1M tokens without collapse — [arXiv 2410.07145](https://arxiv.org/abs/2410.07145)
- **[NLP, 2025] Unexplored states.** "Understanding and Improving Length Generalization in Recurrent Models," Buitrago & Gu, ICML 2025. Recurrent models fail to length-generalize when training explores only part of the reachable state distribution. Simple state-passing interventions (initialize with Gaussian noise or with the final state of another sequence) for **500 post-training steps (about 0.1% of pretraining)** give generalization from 2K to 128K — [arXiv 2507.02782](https://arxiv.org/abs/2507.02782); [PMLR v267](https://proceedings.mlr.press/v267/buitrago25a.html)
- **[Vision, 2024] Recency/decay as inductive bias.** Han et al. find that Mamba's **forget gate** (data-dependent decay) is one of the two key contributors to its vision performance. In vision it mainly supplies local bias and positional information, and a suitable positional encoding (e.g., LePE/CPE) can substitute while keeping parallel computation — [arXiv 2405.16605](https://arxiv.org/abs/2405.16605); [MLLA README](https://github.com/LeapLabTHU/MLLA)
- **[NLP, 2024] Stability as a positive.** Halloran et al. (TMLR 2025) argue via Lyapunov analysis that Mamba's recurrent dynamics are stable, making Mamba LLMs **significantly more robust than Transformers to mixed-precision + PEFT fine-tuning** (see Section 6) — [arXiv 2406.00209](https://arxiv.org/abs/2406.00209)

### Inferences
- In Mamba, the data-dependent exponential decay is both the strength and the weakness. It gives a strong recency/locality prior, with cheap, smooth, distance-decaying aggregation that suits signals with local correlation (images, audio). It also forgets: distant exact details decay unless Δ learns to "hold" them, and the non-negative real spectrum rules out oscillatory or sign-flipping state dynamics (parity, rotations).
- Train-length-bounded ERF and state collapse matter for patch-based SR. A Mamba trained on 32×32 LR patches may behave differently on larger inference tiles. Keeping inference tiles close to the training patch size, or using state-passing/longer-crop fine-tuning, is the low-risk choice. This is an inference from NLP findings and has not been verified on LF data.

### Gaps
- No vision paper was found that directly tests Mamba's **resolution extrapolation** (train on small crops, test on large) against attention in the way DeciMamba/Stuffed Mamba do for text. Some resolution-scaling work exists (e.g., fractal-traversal Vision Mamba, [arXiv 2505.14062](https://arxiv.org/abs/2505.14062)), but its content was not verified here.
- Whether the state-tracking limits (TC⁰, parity) have any practical relevance for low-level vision is unaddressed in the literature I found. Likely they do not.

## 4. Theoretical unification: SSD (Mamba-2), Mamba as gated linear attention, the hidden attention of Mamba

### Takeaway
Selective SSMs and attention are two points in one family: **sequence mixing by a (masked) matrix M = L ∘ (C Bᵀ)**. In softmax attention, M is full-rank, normalized, and content-sharp. In SSMs/linear attention, M is semiseparable/low-rank with a data-dependent cumulative-decay mask L. Mamba ≈ single-head linear attention + input gate + **forget gate (decay)** + shortcut, without normalization, plus a different block design. Its implicit attention matrices can be extracted and are interpretable, but they are smoother and less sharp than softmax attention.

### Cited Findings
- **[Theory, 2024] Structured State Space Duality (SSD).** Dao & Gu, ICML 2024. SSMs and variants of attention are connected through **structured semiseparable matrices**. When Aᵢ is a scalar, the SSM equals masked attention, M = L ∘ (C Bᵀ), with L a 1-semiseparable cumulative-product (decay) mask. This yields a quadratic "attention mode" and a linear "recurrent mode" of the same layer, and a chunked algorithm mixing both on tensor cores — [arXiv 2405.21060](https://arxiv.org/abs/2405.21060); [Dao blog Part III](https://tridao.me/blog/2024/mamba2-part3-algorithm/); survey restatement of M = L∘(CBᵀ) in [arXiv 2503.18970](https://arxiv.org/abs/2503.18970)
- **[Vision, 2024] Mamba as linear attention.** "Demystify Mamba in Vision: A Linear Attention Perspective," Dongchen Han et al. (Tsinghua, Gao Huang group), NeurIPS 2024. Selective SSM is reformulated as a linear-attention Transformer with **six distinctions**: input gate (Δᵢ), forget gate (Ãᵢ), shortcut (D⊙xᵢ), no attention normalization, single head, and modified (Mamba-style gated) block design. Ablations on ImageNet show the **forget gate and the block design are the core contributors**, while the other four matter less. The resulting MLLA (renamed MILA in the final version) uses positional encodings in place of the recurrent forget gate. It "outperforms various vision Mamba models" in classification and dense prediction (MILA-B reported at 85.3% top-1) with parallel computation and faster inference — [arXiv 2405.16605](https://arxiv.org/abs/2405.16605); [MLLA README](https://github.com/LeapLabTHU/MLLA); [NeurIPS poster](https://neurips.cc/virtual/2024/poster/95559)
- **[NLP+Vision, 2024] Hidden attention.** "The Hidden Attention of Mamba Models," Ali, Zimerman, Wolf; ACL 2025. Beyond the convolutional and recurrent views, Mamba layers can be viewed as **implicit data-controlled attention**. Mamba yields about **three orders of magnitude more attention matrices than Transformers**, since each channel has its own. Explainability methods (attention rollout, attribution) applied to Vim give metrics comparable to ViT — [arXiv 2403.01590](https://arxiv.org/abs/2403.01590); [HiddenMambaAttn README](https://github.com/AmeenAli/HiddenMambaAttn)
- **[Vision, 2024] Causal vs fully-visible mixing.** MambaOut frames SSM token mixing as inherently **causal** (token t sees only tokens ≤ t), whereas attention is fully visible by default. Converting ViT attention to causal mode **reduces ImageNet accuracy**, which the authors take as evidence that causal mixing is unnecessary or harmful for understanding tasks — [MambaOut README Fig. 3](https://github.com/yuweihao/MambaOut); [arXiv 2405.07992](https://arxiv.org/abs/2405.07992)
- **[NLP, 2025] Hidden-attention lens explains the recall gap.** Bick et al. find that SSM G&A heads produce smoother attention patterns than the sharp transitions effective retrieval requires — [arXiv 2504.18574](https://arxiv.org/abs/2504.18574)
- **[NLP, 2023/2025] The broader family.** The Zoology repo lists H3, Hyena, RetNet, GLA, Based, Mamba, Mamba-2, DeltaNet, Gated DeltaNet ("Improving Mamba2 with Delta Rule," ICLR 2025), and RWKV-7 as variants of the same sub-quadratic sequence-mixer family, all evaluated on MQAR as a function of state size — [Zoology README](https://github.com/HazyResearch/zoology)

### Inferences
- Under this unification, the trade-off reduces to three properties of M:
  - **Rank/capacity**: softmax is full-rank, SSM is semiseparable with rank ≤ N.
  - **Sharpness**: softmax normalization and exponentiation give near one-hot selection; linear/SSM forms are smooth.
  - **Mask structure**: SSM has causal cumulative decay; attention has none unless masked.
- These three properties map directly onto the empirical findings: recall/copying (rank and sharpness), locality and forgetting (decay mask), and scan-order dependence in vision (causality).
- In vision, the forget gate's role (locality + position) can be replaced by positional encodings or convolutions. This suggests a Mamba block's benefit in restoration may come partly from its *gated block design and decay-induced locality*, not only from the "SSM-ness". That is a testable ablation for LFTransMamba: replace SS2D with MLLA-style linear attention + LePE/CPE.

### Gaps
- No paper found that applies the SSD/linear-attention lens specifically to image restoration/SR to say *which* of the six distinctions matter for low-level tasks; Han et al. ablate on classification and dense prediction only.

## 5. Vision-specific analysis: Vim, VMamba, MambaOut, causal 2D scanning, scan direction, ERF, local pixel forgetting, artifacts

### Takeaway
In vision, Mamba's sequence-model assumptions clash with 2D/4D data: flattening is arbitrary, the scan is causal, and decay is measured in 1D sequence distance, not spatial distance. This produces scan-order dependence, cross-shaped ERFs, "local pixel forgetting", and high-norm artifact tokens. Remedies are multi-directional scans, local/windowed scans, depthwise convolutions, registers, and non-causal variants. MambaOut shows the SSM is unnecessary for 224² classification (short sequences) but beneficial for detection/segmentation (about 4K tokens). A 2026 representation analysis suggests VMamba's dense-task advantage relates to how evidence is encoded (token directions vs norms), not simply to sequence length.

### Cited Findings
- **[Vision, 2024] Vim.** Zhu et al., ICML 2024. "Representing visual data is challenging for SSMs due to the position-sensitivity of visual data and the requirement of global context." Vim uses **bidirectional** SSMs plus position embeddings. Placing the class token in the middle of the sequence improved accuracy (Vim-Ti 76.1%, Vim-S 80.5% / 81.6% with fine-grained FT, Vim-B 81.9%) — [Vim README](https://github.com/hustvl/Vim); [arXiv 2401.09417](https://arxiv.org/abs/2401.09417)
- **[Vision, 2024] VMamba / SS2D.** Liu et al., NeurIPS 2024. The 2D Selective Scan (SS2D) traverses **four scanning routes** to "bridge the gap between the ordered nature of 1D selective scan and the non-sequential structure of 2D vision data." The README claims VMamba has a **global effective receptive field** (ERF visualizations) — [VMamba README](https://github.com/MzeroMiko/VMamba); [arXiv 2401.10166](https://arxiv.org/abs/2401.10166)
- **[Vision, 2024/25] ERF shape.** EfficientViM (CVPR 2025) shows qualitatively that ResNet-50 has a small ERF (locality of convolution) and DeiT-S attention concentrates near the center pixel, while VMamba's ERF is global but has an **unnatural cross pattern** because the SSM runs on the flattened image along rows and columns. VSSD-T has a better global ERF "yet it still largely depends on the close region" — [arXiv 2411.15241](https://arxiv.org/abs/2411.15241)
- **[Vision, 2024] Flattening breaks 2D locality.** LocalMamba (Huang et al.) states: "Traditional ViM approaches, which flatten spatial tokens, overlook the preservation of local 2D dependencies, thereby elongating the distance between adjacent tokens." Windowed local scans plus a per-layer search over scan directions improve Vim-Ti by **+3.1%** ImageNet at the same 1.5G FLOPs, and different layers prefer different scan patterns — [arXiv 2403.09338](https://arxiv.org/abs/2403.09338); [LocalMamba README](https://github.com/hunto/LocalMamba)
- **[Vision/IR, 2024] Local pixel forgetting and channel redundancy.** MambaIR (Guo et al., ECCV 2024) identifies two problems of vanilla Mamba for restoration. **Local pixel forgetting**: spatially adjacent pixels end up far apart in the flattened 1D sequence and are forgotten by the recursive decay. **Channel redundancy**: the many hidden states needed for long-range memory become redundant across channels. Fixes are a depthwise-conv local enhancement and channel attention. MambaIR reports up to **+0.45 dB over SwinIR** on SR at similar cost — [arXiv 2402.15648](https://arxiv.org/abs/2402.15648); [ECCV 2024](https://eccv2024.ecva.net/virtual/2024/poster/310)
- **[Vision/IR, 2025] Causality limitation in restoration.** MambaIRv2 (CVPR 2025): "the inherent causal modeling limitation of Mamba, where each token depends solely on its predecessors in the scanned sequence, restricts the full utilization of pixels across the image." It proposes an attentive state-space equation that "attends beyond the scanned sequence" to give Mamba ViT-like non-causal ability — [MambaIR/MambaIRv2 README](https://github.com/csguoh/MambaIR)
- **[Vision, 2024/25] Artifacts and registers.** "Mamba®: Vision Mamba ALSO Needs Registers" (Wang et al., CVPR 2025) finds that Vim shows feature-map artifacts (**high-norm tokens in low-information background regions**) that are **much more severe than in ViTs**, present even in tiny models. The fix is evenly inserting register tokens through the sequence and recycling them for prediction. Reported ImageNet accuracy is Mamba®-S/B/L 81.4/83.0/83.6% with an improved recipe — [arXiv 2405.14858](https://arxiv.org/abs/2405.14858); [Mamba-Reg README](https://github.com/wangf3014/Mamba-Reg)
- **[Vision, 2024/25] MambaOut.** Yu & Wang, CVPR 2025. Mamba is "ideally suited for tasks with long-sequence and autoregressive characteristics." Image classification has neither, so the authors remove the SSM from Mamba blocks, leaving Gated CNN blocks. The resulting **MambaOut beats all visual Mamba models on ImageNet** (MambaOut-T/S/B: 82.7/84.1/84.2% top-1; Kobe variant 80.0% at 9.1M params). On COCO detection and ADE20K segmentation (long-sequence, about 4K tokens), **MambaOut cannot match state-of-the-art visual Mamba models**, supporting the hypothesis that the SSM helps in long-token dense tasks — [MambaOut README](https://github.com/yuweihao/MambaOut); [arXiv 2405.07992](https://arxiv.org/abs/2405.07992)
- **[Vision, 2026] Norm vs direction.** "Norm or Direction? Decoding Vision Mambas for High-Resolution Vision," Jin Yu & Juyoun Park, arXiv July 2026. CKA analysis shows VMamba's final-stage representations differ from MambaOut's. MambaOut concentrates class evidence in **high-norm foreground tokens** (aligned with Grad-CAM). VMamba's high-norm tokens sit mostly in the **background**, while its discriminative signal lives in token **directions**. MambaOut's reliance on sparse dominant tokens becomes less stable as token counts grow, which explains why VMamba wins on segmentation under full fine-tuning. The authors attribute this to evidence organization "rather than to the SSM mechanism or sequence length alone," and concede the SSM cannot be isolated without targeted ablations — [arXiv 2607.18625](https://arxiv.org/abs/2607.18625)
- **[Vision, 2024] Do multi-direction scans matter?** An experimental study on remote-sensing segmentation argues earlier Vision Mamba papers lacked scan ablations. It notes that VMamba's four-direction scan beat unidirectional scanning by only **0.3%** on ImageNet, within training variance — [arXiv 2405.08493](https://arxiv.org/abs/2405.08493)
- **[Vision, 2025] Patch order in MRI segmentation.** "Flatten Wisely" isolates patch-order effects across 21 experiments and 12 primitive scan paths (single, bidirectional, multi-path) — [arXiv 2507.13384](https://arxiv.org/abs/2507.13384)
- **[Vision, 2026] Scan order and robustness.** Partial Ring Scan (PRIS-Mamba, ICML 2026) argues fixed scan paths disrupt spatial adjacency and hurt robustness. Fixed-path scans reportedly **lose 1 to 2% under rotation**, while ring-based traversal is more robust (snippet-level; not verified in full text) — [arXiv 2602.04170](https://arxiv.org/abs/2602.04170); [ICML 2026 poster](https://icml.cc/virtual/2026/poster/66490)
- **[Vision, 2024] Explainability.** Vim's hidden attention maps (merged over the two scan directions) give explainability metrics comparable to ViT at similar sizes — [arXiv 2403.01590](https://arxiv.org/abs/2403.01590)

### Inferences
- **Mechanism summary for vision.** A selective SSM applied to an image computes, for each token, a decaying weighted sum over tokens earlier *in scan order*. Three consequences follow.
  1. Spatial neighbors across row or column boundaries are far apart in sequence order, so they are forgotten (local pixel forgetting, cross-shaped ERF).
  2. Information flows one way, which needs multi-directional scans or non-causal fixes for symmetric dependencies.
  3. The decay acts as a learned locality prior, which helps restoration but must be complemented by convolutions for exact neighborhood modeling.
  Attention has none of these order artifacts but costs O(L²).
- **For light fields (inference, not tested in literature):** 4D LF data adds a second arbitrary ordering choice (angular u,v vs spatial h,w). LFTransMamba's 3D/4D scans (`cross_selective_scan3D/4D` in `models/LFTransMamba.py`) use macro-pixel-style rearrangements, e.g. `'b c (h u) (w v) -> b c (h w) (u v)'`, which make the 25 angular samples of a pixel contiguous in the scan. Angular correlations (disparity-related) then become short-range in 1D and survive the decay, while far spatial positions rely on the decay-limited state. The causal and scan-order findings above (LocalMamba, MambaIRv2, PRIS) imply that **scan ordering across views is a real design variable** for LFSR. The fact that VMamba's 4-way scan bought only 0.3% on ImageNet should not be over-generalized to 4D data, where flattening distortions are larger.
- **MambaOut criterion for LF:** with D=64, 6D = 384 tokens. Angular-only sequences (25 tokens) are far "short," so attention or convolution is the natural choice there. Per-view spatial (1024) and full 4D (25,600) are "long," so the SSM is justified mainly for 4D/EPI-scale mixing.
- High-norm artifact tokens (Mamba®) and channel redundancy (MambaIR) are plausible but unverified failure modes in LFSR features. They could be checked cheaply by inspecting feature-norm maps of the SS2D/SS4D outputs.

### Gaps
- I found **no quantitative ERF-decay curve** comparing Mamba vs attention vs CNN as a function of 2D distance; available ERF evidence is qualitative.
- No analysis paper specifically on **scan order in 4D light fields** was found (LF-specific works are covered by another researcher).
- Exact COCO/ADE20K gaps between MambaOut and VMamba could not be read from the paper tables (arXiv blocked).

## 6. Training dynamics, data efficiency, optimization stability

### Takeaway
Evidence is thinner and mixed. Mamba is **less sample-efficient than Transformers on copying/retrieval-type tasks**, but more sample-efficient on sparse parity and reportedly in some low-data domains. SSMs are **sensitive to recurrent-dynamics precision during training**: the official repo recommends fp32 master parameters. Yet a 2025 TMLR study finds Mamba LLMs *more* stable than Transformers under mixed-precision + PEFT fine-tuning. Supervised Vision Mamba scales poorly (plateau or collapse at large sizes) unless pretrained autoregressively. Recurrent models also need training length matched to state size to learn forgetting.

### Cited Findings
- **[NLP, 2024] Copying sample efficiency.** Transformers learn copying much faster. Mamba needs about 10× more data than Transformers even on short strings (LSTMs about 100×) — [arXiv 2402.01032](https://arxiv.org/abs/2402.01032)
- **[NLP, 2024] Parity sample efficiency.** On sparse parity ICL, Mamba outperforms Transformers, and MambaFormer learns parity with Mamba-like sample complexity. A standard hybrid learns it "with much worse sample efficiency" — [arXiv 2402.04248](https://arxiv.org/abs/2402.04248)
- **[NLP, 2024] Precision sensitivity (official guidance).** The state-spaces/mamba README says: "higher precision for the main model parameters may be necessary, because SSMs are sensitive to their recurrent dynamics. If you are experiencing instabilities, as a first step please try a framework storing parameters in fp32 (such as AMP)." It also warns that frameworks which zero all `nn.Linear` biases after init break the Δ-bias initialization that targets Δ's range — [state-spaces/mamba README](https://github.com/state-spaces/mamba)
- **[NLP, 2024/25] Mamba is more stable under MPFT + PEFT.** "Mamba State-Space Models Are Lyapunov-Stable Learners," Halloran, Gulati, Roysdon (Leidos); TMLR 2025 (ICLR 2025 workshop). Transformer LLMs "may drastically diverge from their full-precision counterparts" under mixed-precision fine-tuning + PEFT, while Mamba LLMs are "significantly more stable." The authors attribute this to Lyapunov-stable recurrent dynamics. LoRA on different Mamba parameters acts as a regularizer — [arXiv 2406.00209](https://arxiv.org/abs/2406.00209); [TMLR 2025 listing](https://mlanthology.org/tmlr/2025/halloran2025tmlr-mamba)
- **[Vision, 2024/25] Scaling Vision Mamba.** "Autoregressive Pretraining with Mamba in Vision" (ARM; Ren et al., ICLR 2025). Supervised Vim models plateau or even collapse in training when scaled to very large sizes. Autoregressive pretraining, which suits Mamba's unidirectional recurrence, gives Mamba-B **83.2%** ImageNet (+2.0 over supervised) and a huge model **85.0%**, the largest Vision Mamba at the time — [arXiv 2406.07537](https://arxiv.org/abs/2406.07537); [ICLR 2025](https://proceedings.iclr.cc/paper_files/paper/2025/hash/ca96d34b583999a43e75d54a4146b083-Abstract-Conference.html)
- **[Vision, 2024] Training recipes.** Mamba® trains with a multi-stage recipe (128² pretraining, then 224² intermediate, then fine-tune), and its README reports higher accuracies than the paper "as we improved the training recipe." This indicates notable recipe sensitivity for pure-Mamba ViTs — [Mamba-Reg README](https://github.com/wangf3014/Mamba-Reg)
- **[NLP, 2024] Length vs state size.** The minimum training length required for a recurrent model to learn forgetting scales **linearly with state size**. Too-short training sequences relative to state size lead to state collapse at longer lengths — [arXiv 2410.07145](https://arxiv.org/abs/2410.07145)
- **[NLP, 2025] Cheap post-training fix.** About 500 steps of state-passing post-training (about 0.1% of pretraining compute) fix length generalization (2K to 128K) — [arXiv 2507.02782](https://arxiv.org/abs/2507.02782)
- **[Other domains, 2024] Low-data evidence (weak).** In PDE neural operators, Mamba reportedly achieves the lowest error as dataset size decreases on Darcy flow — [arXiv 2410.02113](https://arxiv.org/abs/2410.02113). MaIL (imitation learning) reports Mamba beating Transformers on LIBERO with limited data and matching them with full data — [arXiv 2406.08234](https://arxiv.org/abs/2406.08234). Both are single-paper, domain-specific claims.
- **[NLP, 2025] Training throughput.** In reranking, Mamba has lower training throughput than FlashAttention Transformers despite comparable quality — [RepL4NLP 2025](https://aclanthology.org/2025.repl4nlp-1.12.pdf)

### Inferences
- For SR training, three practical consequences follow from the above:
  1. Keep SSM parameters (A_log, Δ bias, D) in fp32 under AMP. LFTransMamba's VMamba-derived SS2D already has `force32`-style switches, which should not be disabled casually.
  2. Do not zero-init the Δ projection bias.
  3. Expect pure-SSM models to be recipe-sensitive; hybrids with attention and convolution are typically easier to optimize.
- The Jelassi data-efficiency gap concerns *exact copying*. If an LFSR model must reproduce exact high-frequency textures from other views (a copy-like operation), attention is likely the more sample-efficient component. This is an inference only.

### Gaps
- **No controlled study** was found comparing Mamba vs attention data-efficiency or optimization stability in image restoration/SR with matched size and recipe.
- No primary evidence was found about loss-landscape/gradient-norm differences between SSM and attention blocks in vision.

## 7. Other notable 2025–2026 analysis papers on SSM vs attention (beyond those above)

### Takeaway
From 2025 to 2026 the field converged on the view that **fixed-state recurrences trade recall for efficiency**. Research shifted to (a) mechanistic accounts of the gap (G&A heads, interference), (b) state-capacity scaling (sparse/expanded states, log-linear memory), (c) state-tracking fixes (negative or complex eigenvalues, Mamba-3), and (d) length-generalization fixes. Several very recent (2026) items were found only as search snippets and need verification.

### Cited Findings
- **[NLP, ICML 2025]** Gather-and-Aggregate (Bick, Xing, Gu): retrieval concentrated in a few heads, with SSM heads too smooth (see Section 2) — [arXiv 2504.18574](https://arxiv.org/abs/2504.18574)
- **[NLP, ICML 2025]** Length generalization via state passing (Buitrago & Gu) — [arXiv 2507.02782](https://arxiv.org/abs/2507.02782)
- **[NLP/Theory, NeurIPS 2025]** HAX (Zhan et al.): pure SSMs need state linear in the number of entries for multi-query joint recall; context-dependent sparse attention fixes it — [arXiv 2507.00449](https://arxiv.org/abs/2507.00449)
- **[NLP, ICLR 2026]** Mamba-3: trapezoidal discretization, complex states for state tracking, MIMO for decode efficiency — [arXiv 2603.15569](https://arxiv.org/abs/2603.15569)
- **[NLP, ICLR 2026] "Scaling Linear Attention Capacity" (Sparse State Expansion).** The state is expanded into N partitions with a write-read gate. Pure linear variants "still lag behind Transformer," while the hybrid SSE-H approaches Transformer-level retrieval (snippet-level) — [ICLR 2026 PDF](https://proceedings.iclr.cc/paper_files/paper/2026/file/d3b8ce5e27b1c622d1b3da22b215e59b-Paper-Conference.pdf)
- **[NLP, 2025] StateX.** Post-training state expansion of pretrained RNNs improves recall and ICL cheaply — [arXiv 2509.22630](https://arxiv.org/abs/2509.22630)
- **[NLP, 2026] Sparse Delta Memory.** Reported highest RULER recall among fixed-state architectures at 1.4B and 8B, and notes that increasing linear-attention state size improves recall at higher FLOP cost (snippet-level) — [emergentmind 2607.07386](https://www.emergentmind.com/papers/2607.07386)
- **[NLP, 2026] Log-linear memory.** "Adaptive Memory Decay for Log-Linear Attention" builds on log-linear attention (Fenwick-tree memory whose state grows logarithmically with length), a middle point between O(1)-state SSMs and O(L) KV cache (snippet-level) — [arXiv 2605.06946](https://arxiv.org/abs/2605.06946)
- **[Theory, Sep 2026] "A Comparative Analysis of Attention versus State-Space Models for In-Context Learning".** Proposes "belief geometry," a unified framework for comparing the representational capabilities of broad classes of attention and SSMs. The theorems could not be verified (abstract-level only) — [arXiv 2609.32341](https://arxiv.org/abs/2609.32341)
- **[NLP, Sep 2026] "Anatomy of Associative Recall in Fixed-State Recurrences: A Matched-State Decomposition, an Interference Wall, and a Curriculum That Breaks It"** (title-level only; contents not verified) — [arXiv 2609.16183](https://arxiv.org/abs/2609.16183)
- **[Theory/NLP, 2026, unverified]** "Rethinking State Tracking in Recurrent Models Through Error Control Dynamics" ([arXiv 2605.07755](https://arxiv.org/abs/2605.07755)) and "State Propagation Also Satisfies: A Complex-Valued State-Space Model for Deterministic State Tracking" ([arXiv 2608.03425](https://arxiv.org/abs/2608.03425)). The latter claims success where Transformers and Mamba fail on state tracking (snippet only).
- **[Vision, 2026]** "Norm or Direction?" representation-level VMamba vs MambaOut analysis (Section 5) — [arXiv 2607.18625](https://arxiv.org/abs/2607.18625)
- **[Vision, ICML 2026]** Partial Ring Scan: scan order and rotation robustness (Section 5) — [arXiv 2602.04170](https://arxiv.org/abs/2602.04170)
- **[Survey, 2025]** S4-to-Mamba survey: attention keeps the advantage on exact retrieval and associative recall, while SSMs are more efficient in long-context regimes — [arXiv 2503.18970](https://arxiv.org/abs/2503.18970)

### Inferences
- **Consolidated trade-off table (synthesized from Sections 1 to 7):**

| Property | Selective SSM (Mamba) | Softmax attention | Mechanistic reason |
|---|---|---|---|
| Time / memory vs length L | O(L) / O(1) state at inference | O(L²) compute, O(L) KV cache | recurrence vs all-pairs |
| Wall-clock win region | ≳2K tokens (kernel); decoding throughput 4–5× | ≲2K tokens with FlashAttention | scan is memory-bound; Mamba-2 SSD uses tensor cores |
| Exact copy / MQAR / retrieval | weak; capacity ∝ state size | strong (2-layer copies exp-length strings) | lossy fixed state, smooth "attention" vs lossless cache, sharp softmax |
| State tracking (parity, S5) | Mamba-1/2 fail parity; both in TC⁰ | fails S5 too; needs depth | non-negative real eigenvalues; fixed by negative/complex eigenvalues |
| Star-free / flip-flop, bounded hierarchy | strong, length-generalizing | struggles | recurrence natively tracks finite state |
| Length extrapolation | good on induction heads; but ERF bounded by train length, state collapse | positional-encoding-limited | unexplored states, over-parameterized state |
| Inductive bias | recency/locality via data-dependent decay; causal, order-dependent | permutation-equivariant, needs positional encoding, no locality prior | forget gate = decay mask L in SSD |
| Vision-specific | scan-order dependence, cross-shaped ERF, local pixel forgetting, high-norm artifacts | no order artifacts; quadratic at high resolution | 2D→1D flattening + causality |
| Stability | fp32 params recommended; stable under MPFT+PEFT; pure Vision Mamba hard to scale supervised | well-understood recipes | recurrent dynamics |

- The literature's consistent recommendation is **"mostly SSM + a little attention."** For example, NVIDIA's best 8B hybrid uses 7% attention layers, and Wen et al. show one attention layer suffices in theory. That is the mechanism-level rationale for hybrid LFSR designs like LFTransMamba: attention for exact correspondence and retrieval, SSM for cheap long 4D aggregation.

### Gaps
- Several 2026 items (belief geometry, Anatomy of Associative Recall, Sparse Delta Memory, error-control state tracking, complex-valued state propagation) were only visible as search snippets. Their claims, authors, and venues need direct verification before citing in a final report.
- I found no 2025–2026 *vision-specific* theory paper analyzing SSM vs attention expressivity for dense prediction or restoration. Vision analyses remain empirical (MambaOut, Norm-or-Direction, scan-order studies).
