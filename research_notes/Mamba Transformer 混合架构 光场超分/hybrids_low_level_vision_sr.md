# Mamba and Hybrid Mamba + Attention Architectures for Low-Level Vision (SISR / VSR / General Restoration, excluding Light Field)

Scope note: covers single-image SR, video/burst SR, and general restoration (denoising, deblurring, deraining, etc.), plus NTIRE reports from non-light-field SR tracks. Light-field SR (LFMamba, LFTransMamba, NTIRE LFSR) is handled by another researcher.

Method note (read this first): direct access to arxiv.org, openaccess.thecvf.com, alphaxiv, Semantic Scholar and HuggingFace was blocked from this environment. Paper-level facts below come from (a) official GitHub READMEs, downloaded directly (marked "README"), and (b) search-engine extracts of the arXiv/CVF pages, cited to the primary URL. Where a number came only from a third-party summary (Pith, alphaxiv overview, themoonlight, etc.), it is labeled "third-party summary" and should be checked against the PDF before it goes in a final report.

## Q1. Pure-Mamba restoration/SR models: what problems did they identify, and how did they fix them?

### Takeaway
Every serious "pure" Mamba restorer turned out not to be pure. Each one adds a local operator (convolution, windowed or striped scanning, channel attention) to fix problems that come from flattening 2D images into 1D causal scans. The problems cited across papers are local pixel forgetting, channel redundancy, causal (one-directional) dependence, long-range decay, broken locality and continuity, and the cost of scanning in many directions.

### Cited Findings
**MambaIR (2024)**
- "MambaIR: A Simple Baseline for Image Restoration with State-Space Model", Hang Guo, Jinmin Li, Tao Dai, Zhihao Ouyang, Xudong Ren, Shu-Tao Xia, ECCV 2024, arXiv 2402.15648 — [ECCV PDF](https://www.ecva.net/papers/eccv_2024/papers_ECCV/papers/02740.pdf); [arXiv](https://arxiv.org/html/2402.15648v3)
  - Problem 1, **local pixel forgetting**: pixels that are neighbours in 2D can end up far apart in the flattened 1D token sequence. Fix: a local convolution after the VSSM, using a bottleneck (channels compressed by γ, then expanded). — [arXiv 2402.15648](https://arxiv.org/html/2402.15648v3); [emergentmind summary](https://www.emergentmind.com/topics/mambair)
  - Problem 2, **channel redundancy**: SSMs use many hidden states to remember long-range dependencies, and visualised channel activations show clear redundancy. Fix: SE-style channel attention inside the Residual State Space Block (RSSB = VSSM + local conv + channel attention + learnable skip scale). — [arXiv 2402.15648](https://arxiv.org/html/2402.15648v3)
  - Reported numbers (README): classic SR ×4 Urban100 27.68 dB / 0.8287; ×2 34.15; ×3 29.93. MambaIR-light ×4 Urban100 26.75. Real denoising SIDD 39.89. Gaussian denoising Urban100 σ=15/25/50: 35.17/32.99/30.07. JPEG CAR Classic5 q10/30/40: 30.27/33.74/34.53. — [MambaIR GitHub README](https://github.com/csguoh/MambaIR)
  - **Complexity-accounting caveat**: the README says MambaIR's earlier #params/MACs, computed with `thop`, had a bug that missed parameters. The corrected `fvcore` count is "larger than the reported one", and lightweight-SR results were fixed in an Oct-2024 arXiv revision. — [MambaIR GitHub README, 2024-08-19 and 2024-10-15 news](https://github.com/csguoh/MambaIR)
  - Classic-SR params: one third-party summary gives MambaIR at 20.6M vs HAT at 20.8M, with HAT ×4 Urban100 at 27.97 dB. — [Pith summary of Contrast](https://pith.science/paper/2501.13353) (third-party summary)

**MambaIRv2 (2025)**
- "MambaIRv2: Attentive State Space Restoration", Hang Guo, Yong Guo, Yaohua Zha, Yulun Zhang, Wenbo Li, Tao Dai, Shu-Tao Xia, Yawei Li, CVPR 2025, arXiv 2411.15269 — [CVPR PDF](https://openaccess.thecvf.com/content/CVPR2025/papers/Guo_MambaIRv2_Attentive_State_Space_Restoration_CVPR_2025_paper.pdf); [arXiv](https://arxiv.org/html/2411.15269v2)
  - Problem: Mamba's **causal modeling** ("each token depends solely on its predecessors in the scanned sequence") restricts the full use of pixels in the image. Fix: an **attentive state-space equation (ASE)** that "allows to attend beyond the scanned sequence", so the image can be unfolded "with just one single scan". Plus **semantic-guided neighboring (SGN)**, which reorders tokens so that distant but similar pixels sit close together in 1D and long-range decay is reduced. — [MambaIR/MambaIRv2 README abstract](https://github.com/csguoh/MambaIR); [CVPR PDF](https://openaccess.thecvf.com/content/CVPR2025/papers/Guo_MambaIRv2_Attentive_State_Space_Restoration_CVPR_2025_paper.pdf)
  - Claimed: +0.35 dB over SRFormer on lightweight SR with 9.3% fewer params, and up to +0.29 dB over HAT on classic SR. The 0.29 dB is for ×2 on Manga109. — [README](https://github.com/csguoh/MambaIR); [arXiv 2411.15269](https://arxiv.org/html/2411.15269v2)
  - README numbers: classic SR ×4 Urban100 27.89 / 0.8344 (×2 34.49, ×3 30.28). Light ×4 Urban100 26.82 (light ×2 33.26). Gaussian DN σ15 Urban100 35.42. JPEG q10/30/40 Classic5 30.37/33.81/34.64. — [MambaIR GitHub README](https://github.com/csguoh/MambaIR). The README does not say which size variant (S/B/L) the "SR4" row is.
  - MambaIRv2-light ×2: 774K params / 286.3G FLOPs, vs MambaIR-light 905K / 334.2G. Overall about 43% fewer params and 50% fewer FLOPs than MambaIR. — [arXiv 2411.15269 (search extract)](https://arxiv.org/html/2411.15269v2)
  - **MambaIRv2 is a hybrid** (see Q2): it interleaves window MHSA with the ASSM.

**MaIR (2025)**
- "MaIR: A Locality- and Continuity-Preserving Mamba for Image Restoration", Boyun Li, Haiyu Zhao, Wenxin Wang, Peng Hu, Yuanbiao Gou, Xi Peng, CVPR 2025, arXiv 2412.20066 — [GitHub README](https://github.com/XLearning-SCU/2025-CVPR-MaIR); [arXiv](https://arxiv.org/abs/2412.20066)
  - Problems: flattening 2D images into 1D row/column sequences "overlooks (i) the local relationships and spatial continuity inherent in natural images, and (ii) the discrepancies among sequences unfolded through totally different ways." Fixes: **Nested S-shaped Scanning (NSS)**, which uses stripe-based regions for locality, an S-shaped path for continuity, and a shift-stripe step between modules. **Sequence Shuffle Attention (SSA)** then aggregates the four scanned sequences with channel-wise attention weights instead of summing them. Claims to beat 40 baselines on 14 datasets for SR, denoising, deblurring and dehazing. — [MaIR README](https://github.com/XLearning-SCU/2025-CVPR-MaIR)
  - Margins are small. Summaries report Urban100 gains over MambaIR of 0.03–0.12 dB, and one gives 26.90 dB on Urban100 ×4 (probably the lightweight setting), +0.08 dB over the best Mamba baseline. A critical review flags 0.03–0.07 dB ablation margins as statistically fragile. — [liner review](https://liner.com/review/mair-localityand-continuitypreserving-mamba-for-image-restoration); [Pith review](https://pith.science/paper/2412.20066) (third-party summaries)

- **EAMamba** — "EAMamba: Efficient All-Around Vision State Space Model for Image Restoration", Yu-Cheng Lin, Yu-Syuan Xu, Hao-Wei Chen, Hsien-Kai Kuo, Chun-Yi Lee, ICCV 2025, arXiv 2506.22246. Names two Vision-Mamba problems in low-level vision: "computational complexity that scales with the number of scanning sequences and local pixel forgetting". Fixes: a Multi-Head Selective Scan Module (MHSSM) that aggregates multiple scan sequences with no extra complexity or params, and "all-around" scanning patterns. Reports a 31–89% FLOPs reduction vs existing low-level Vision Mamba methods at "favorable" quality for SR, denoising, deblurring and dehazing. — [EAMamba README](https://github.com/daidaijr/EAMamba); [ICCV PDF](https://openaccess.thecvf.com/content/ICCV2025/papers/Lin_EAMamba_Efficient_All-Around_Vision_State_Space_Model_for_Image_Restoration_ICCV_2025_paper.pdf)
- **Progressive Split Mamba (PS-Mamba)** — "Progressive Split Mamba: Effective State Space Modelling for Image Restoration", Hassanin, Moustafa, Deng, Radwan, arXiv 2603.09171 (Mar 2026). Says "flattening 2D feature maps into 1D sequences disrupts spatial topology, leading to locality distortion" and that "stability-driven recurrent dynamics of SSMs induce long-range decay". Fix: a progressive split hierarchy (halves → quadrants → octants) plus symmetric cross-scale shortcuts that carry low-frequency global context. Needs no token reordering or multi-directional scans. Tested on SR, denoising and JPEG CAR. — [arXiv 2603.09171](https://arxiv.org/pdf/2603.09171)
- **TAMambaIR** — "Directing Mamba to Complex Textures: An Efficient Texture-Aware State Space Model for Image Restoration", arXiv 2501.16583 (Jan 2025). Modulates Mamba's transition matrix by texture. — [Awesome list](https://github.com/csguoh/Awesome-Mamba-in-Low-Level-Vision); [TS-Mamba paper mentions it](https://arxiv.org/pdf/2508.10453)
- **RestorMamba** — "RestorMamba: An Enhanced Synergistic State Space Model for Image Restoration", ICASSP 2025. — [Awesome list](https://github.com/csguoh/Awesome-Mamba-in-Low-Level-Vision)

### Inferences
- Most "pure Mamba" fixes re-introduce locality: conv in MambaIR, depthwise conv in XYScanNet, stripes/S-scan in MaIR, local+region SSMs in Hi-Mamba, local windows in MambaCSR, splits in PS-Mamba. This points to the main weakness of Mamba for pixel regression being *local, precise* interaction, not global reach. Window attention provides exactly that, which is the core argument for hybrids such as LFTransMamba.
- The PSNR gaps between Mamba and Transformer SR models are small: MambaIR 27.68 vs HAT 27.97 on Urban100 ×4 (third-party HAT figure), and MambaIRv2 27.89 per README. Pure Mamba models did not beat strong window-attention Transformers at classic SR until MambaIRv2, which itself has window attention.

### Gaps
- Could not retrieve exact Urban100/Manga109 ×4 tables for the MambaIRv2 S/B/L variants, MaIR (classic SR), EAMamba, Hi-Mamba, or VmambaIR (PDF access blocked). The README numbers above are the only directly verified ones.
- "LoFormer" (local frequency Transformer for deblurring, ACM MM 2024) is, as far as I know, not Mamba-based. I did not verify it here, so it is not listed as a Mamba model.
- No LAM (Local Attribution Map) diffusion-index numbers for Mamba SR models were found. MambaIR provides ERF-visualization code (`./analysis/`), and MambaIRv2 shows an ERF figure, but no quantitative ERF/LAM values were retrievable. — [MambaIR README](https://github.com/csguoh/MambaIR)

## Q2. Hybrid Mamba + Transformer/attention models for SR/restoration: designs, ablations, and the authors' explanations for complementarity

### Takeaway
Hybrids converge on one division of labour. Window or channel self-attention handles precise, content-adaptive local or channel interactions. Mamba/SSM handles cheap long-range context, and conv blocks often take the highest-resolution stage. The best classic-SR Mamba model, MambaIRv2, is itself a window-MHSA + ASSM hybrid. Clean "remove attention vs remove Mamba" ablations are rare, and one third-party reviewer says complementarity is often asserted but not isolated.

### Cited Findings
- **MambaIRv2 (CVPR 2025) is a hybrid.** The authors say that scanning once in the ASSM frees parameter budget, so they "add window multi-head self-attention to strengthen local interactions". Window MHSA and ASSM form the basic blocks, with progressive local-to-global modeling inside Attentive State Space Groups. — [arXiv 2411.15269](https://arxiv.org/html/2411.15269v2); [alphaxiv summary](https://www.alphaxiv.org/abs/2411.15269)
  - Ablation (MambaIRv2-light ×2, 250K iters): MHSA-only about 32.89 dB Urban100 / 39.11 dB Manga109; full model (MHSA + ASE + SGN) 32.97 / 39.24. So the attentive SSM adds about +0.08 / +0.13 dB on top of a window-attention baseline. — [ResearchGate copy of MambaIRv2](https://www.researchgate.net/publication/386112715_MambaIRv2_Attentive_State_Space_Restoration) (search extract; a third-party summary gives slightly different deltas)
- **Contrast** — "Contrast: A Hybrid Architecture of Transformers and State Space Models for Low-Level Vision", Aman Urumbekov, Zheng Chen, arXiv 2501.13353 (Jan 2025; v2 Mar 2025). Rationale: the Transformer's quadratic cost forces window attention, "which hampers broader context expansion". Mamba has linear complexity, but its approximate (compressed) hidden state loses pixel-level precision needed for SR. So Contrast integrates conv + Transformer + SSM. — [arXiv 2501.13353](https://arxiv.org/abs/2501.13353)
  - Reported (third-party summary): ×4 Urban100 27.92 dB with 14.1M params, vs MambaIR 27.68 (20.6M) and HAT 27.97 (20.8M). The same reviewer says the claimed complementarity "is not isolated by ablation". — [Pith](https://pith.science/paper/2501.13353) (third-party summary, unverified)
- **MatIR** — "MatIR: A Hybrid Mamba-Transformer Image Restoration Model", Juan Wen, Weiyan Hou, Luc Van Gool, Radu Timofte, arXiv 2501.18401 (Jan 2025). Transformer and Mamba blocks are cross-cycled. The Transformer part uses Triangular Window Local Attention (TWLA), meant to reduce the boundary distortion of rectangular windows, plus Channel Global Attention (CGA). The Mamba part uses an Image Restoration State Space (IRSS) module with 4 scan paths. Stated rationale: Mamba for "efficient long-distance modeling", Transformer for "strong contextual learning capability". Covers SR, denoising and deblurring. — [MatIR README](https://github.com/wenjuan7275/MatIR); [arXiv 2501.18401](https://arxiv.org/html/2501.18401v2)
- **TransMamba (deraining)** — "A Hybrid Transformer-Mamba Network for Single Image Deraining", Shangquan Sun, Wenqi Ren, Juxiang Zhou, Jianhou Gan, Rui Wang, Xiaochun Cao, arXiv 2409.00410 (2024). Rationale: deraining Transformers with "fixed-range windows or along channel dimensions" limit non-local receptive fields. Design: dual branch. One branch is a spectral-banded Transformer (self-attention over spectral-domain channels plus a spectral-enhanced FFN); the other is a Mamba branch with cascaded bidirectional SSMs. The branches are fused by channel concat + reduction at every encoder/decoder stage, and trained with a spectral coherence loss. — [TransMamba README](https://github.com/sunshangquan/TransMamba)
- **RestorMixer** — "An Efficient and Mixed Heterogeneous Model for Image Restoration", arXiv 2504.10967 (2025). Three-stage encoder-decoder: lightweight CNN blocks at the highest resolution, then Mamba global modeling combined with multi-scale window Transformer blocks at lower resolutions. A third-party summary reports 35.47 dB average deraining PSNR vs Restormer's 34.46, at ~2.8M vs 26.1M params. — [arXiv 2504.10967](https://arxiv.org/html/2504.10967v1); [GitHub ClimBin/RestorMixer](https://github.com/ClimBin/RestorMixer); numbers via [aimodels.fyi](https://www.aimodels.fyi/papers/arxiv/efficient-mixed-heterogeneous-model-image-restoration) (third-party summary)
  - Criticism: MixerCSeg (arXiv 2603.01361) cites RestorMixer-style hybrids as often "simply stacking" components rather than integrating them. — [MixerCSeg](https://arxiv.org/html/2603.01361v1)
- **T-PMambaSR** — "Transformer-Progressive Mamba Network for Lightweight Image Super-Resolution", Sichen Guo, Wenjie Li, Yuanyang Liu, Guangwei Gao, Jian Yang, Chia-Wen Lin, arXiv 2511.03232; IEEE TIP 2026. Window self-attention + Progressive Mamba (WSML for regional, GSML for global), plus an Adaptive High-Frequency Refinement Module because "fine textures" are lost by both the Transformer and Mamba stages. Motivation: existing Mamba SR "lack smooth transitions between modeling scales". Ablation covers the Multi-scale Window Selective Scan only (best 39.20 dB vs 39.13–39.16 on BSD100 ×2). It does not isolate attention vs Mamba removal. — [arXiv 2511.03232](https://arxiv.org/html/2511.03232v1); [IEEE SPS listing](https://signalprocessingsociety.org/publications-resources/ieee-transactions-image-processing/2026/09/transformer-progressive-mamba-network-lightweight-image-super-resolution)
- **"Hybrid Mamba-Transformer Model for Lightweight Image Super-Resolution"** (ACM, 2025, doi 10.1145/3743093.3771057). Window-scaled cosine attention (Swin-V2 style) + a multi-scale Mamba module. Reports PSNR/SSIM comparable to MambaIRv2's hybrid with about 19% fewer params. — [ACM DL](https://dl.acm.org/doi/10.1145/3743093.3771057) (search extract)
- **SRMamba-T** — "SRMamba-T: Exploring the hybrid Mamba-Transformer network for Single Image Super-Resolution", Neurocomputing vol. 624 (2025), article 129488. — [ACM DL mirror](https://dl.acm.org/doi/10.1016/j.neucom.2025.129488); [Awesome list](https://github.com/csguoh/Awesome-Mamba-in-Low-Level-Vision)
- **MambaFormerSR** — "MambaFormerSR: A Lightweight model for Remote-Sensing Image Super-Resolution", IEEE 2024. — [Awesome list](https://github.com/csguoh/Awesome-Mamba-in-Low-Level-Vision)
- **Edge-Efficient Image Restoration: Transformer Distillation into State-Space Models**, Srinivas Soumitri Miriyala et al., arXiv 2605.02794 (May 2026). Lightweight SSM blocks are feature-distilled to mimic Restormer Transformer blocks. An "Efficient Network Search" then picks task-specific hybrid U-Nets, penalizing Transformer usage as a latency proxy. On a Snapdragon 8 Elite CPU: Restormer 10119.52 ms vs hybrids at 2973 ms for deblurring (3.4×), 5816 ms for deraining (1.74×) and 8666 ms for denoising (1.17×). Quality is "competitive" or close to the Transformer. — [arXiv 2605.02794](https://arxiv.org/abs/2605.02794); [Pith](https://pith.science/paper/2605.02794)
- **Medical/other hybrids**: FGMamba ("Versatile and Efficient Medical Image SR via Frequency-Gated Mamba", arXiv 2510.27296) adds gated spatial/channel attention to a Mamba block. Removing the gated attention changes OCT ×4 PSNR by only 0.0016 dB (20.9765 vs 20.9781). — [arXiv 2510.27296](https://arxiv.org/html/2510.27296). "Bidirectional-Aware Network Combining Transformer and Mamba for HSI Denoising" (IEEE TGRS). — [Awesome list](https://github.com/csguoh/Awesome-Mamba-in-Low-Level-Vision)
- **Theory for complementarity**: "Demystify Mamba in Vision: A Linear Attention Perspective", Dongchen Han et al., NeurIPS 2024, arXiv 2405.16605. Recasts selective SSM as a variant of linear attention that differs in six ways: input gate, forget gate, shortcut, no attention normalization, single head, and block design. The **forget gate** and **block design** are the main drivers. Their MLLA/MILA linear-attention model beats vision Mambas while staying parallelizable. — [arXiv 2405.16605](https://arxiv.org/pdf/2405.16605); [NeurIPS](https://proceedings.neurips.cc/paper_files/paper/2024/hash/e618724ac897c6cf3fbfb273f8695d67-Abstract.html)
- **Surveys on the local-detail gap**: "Visual Mamba: A Survey and New Outlooks" (arXiv 2404.18861) says "extracting local fine-grained features is critical for low-level image tasks, which the vanilla Mamba architecture lacks". — [arXiv 2404.18861](https://arxiv.org/pdf/2404.18861)

### Inferences
- The explanations converge on the following. (a) Mamba compresses context into a fixed-size, input-gated recurrent state. Per the MLLA view, it is gated linear attention, so it gives global but *approximate*, decaying interactions (Contrast: "approximate hidden state loses pixel-level precision"; MambaIRv2/PS-Mamba: long-range decay). (b) Softmax window attention gives exact, content-adaptive, permutation-symmetric interactions within a local neighbourhood. That is what sub-pixel texture reconstruction needs, but it is window-bounded. Interleaving them (MambaIRv2, MatIR, T-PMambaSR, LFTransMamba-style) gives "precise local + cheap global".
- The cleanest internal evidence is MambaIRv2's ablation, where SSM components add about +0.1 dB over a window-MHSA-only lightweight baseline. The HFMN ablation (−0.90 dB without the Mamba attention block) is larger but from a smaller and less rigorous paper. Neither paper ran the symmetric "remove attention" arm.
- For an LFSR competitor, MambaIRv2's "single non-causal scan + window MHSA" recipe and MaIR's stripe/S-scan are the most transferable ideas. They cut scan-direction cost while keeping attention for local precision.

### Gaps
- I found no paper with a clean 2×2 ablation (attention on/off × Mamba on/off) at matched params/FLOPs for classic SR. Contrast's and MatIR's ablation tables could not be read (PDF access blocked).
- The names "HMANet", "MamberIR" and "ShiftwiseConv+Mamba" from the brief returned no Mamba-hybrid restoration paper in my searches. HMANet, as I recall, is a Transformer-only "Hybrid Multi-Axis Aggregation Network" (CVPRW 2024) and not Mamba-based, but this was not verified here.
- No published ERF/LAM comparison between a hybrid and its pure-Mamba and pure-Transformer counterparts was found.

## Q3. NTIRE / challenge evidence in non-light-field SR tracks

### Takeaway
In NTIRE 2025–2026 general SR tracks, Mamba (mostly MambaIRv2) appears as a branch or ensemble member next to HAT. The top PSNR entries and the organizers' conclusions still favour pre-trained Transformer backbones (HAT family), with Mamba as a widely adopted complement.

### Cited Findings
- **NTIRE 2025 Image SR ×4** (Zheng Chen et al., CVPRW 2025, arXiv 2504.14582). Track 1 (PSNR) winner: SamsungAICamera at 33.46 dB. Two teams beat the 2024 best of 31.94 dB, and ten exceeded 31.00 dB. Track 2 (perceptual) winner: SNUCV (score 4.3472). — [arXiv 2504.14582](https://arxiv.org/pdf/2504.14582); [CVPRW PDF](https://openaccess.thecvf.com/content/CVPR2025W/NTIRE/papers/Chen_NTIRE_2025_Challenge_on_Image_Super-Resolution_x4_Methods_and_Results_CVPRW_2025_paper.pdf)
  - Mamba usage: SNUCV used MambaIRv2 for the ×4 stage, followed by a one-step diffusion refinement. BBox ensembled HAT-L with MambaIRv2-L. XiaomiMM is described as integrating Mamba branches into HAT. The conclusions say Transformer–CNN hybrids balance "global context and local details" and "Mamba-based state space models have been widely adopted". — [arXiv 2504.14582 HTML](https://arxiv.org/html/2504.14582v1) (search extract). Note: one search extract identified XiaomiMM as the NTIRE **2024** ×4 PSNR winner (31.94 dB), so whether the "Mamba-in-HAT" description refers to its 2025 entry should be checked. — [NTIRE 2024 ×4 report](https://arxiv.org/pdf/2404.09790)
- **NTIRE 2026 Image SR ×4** ("The Fourth Challenge on Image Super-Resolution (×4) at NTIRE 2026", arXiv 2604.14558). 194 teams registered and 31 submitted valid entries. Track 1: SamsungAICamera 33.73 dB, I2WM&JNU 33.45 dB, SR-Strugglers 31.98 dB. Track 2: SamsungAICamera 4.7853, VEPG 4.7666, HONORAICamera 4.4787. Conclusion: "Pre-trained Transformer-based restoration models remain the strongest foundation for high-fidelity super-resolution." — [arXiv 2604.14558](https://arxiv.org/html/2604.14558v1)
  - One team's write-up: "Training-Free Model Ensemble for Single-Image Super-Resolution via Strong-Branch Compensation" (arXiv 2604.11564). HAT is the base branch and MambaIRv2 with geometric self-ensemble is a compensation branch, fused at the output with no retraining. It gains PSNR over HAT alone and slightly over MambaIRv2 on DIV2K ×4. — [arXiv 2604.11564](https://arxiv.org/pdf/2604.11564)
- **NTIRE 2026 Remote-Sensing Infrared SR ×4** (arXiv 2604.21312): WHU-VIP won (35.96 dB / 0.9236). A dual-branch entry, "Dual-Branch Remote Sensing Infrared Image Super-Resolution" (arXiv 2604.10112), fuses HAT-L and MambaIRv2-L with equal weights (hidden-test score 54.23 = PSNR + 20×SSIM). — [arXiv 2604.21312](https://arxiv.org/html/2604.21312); [arXiv 2604.10112](https://arxiv.org/pdf/2604.10112)
- **NTIRE 2025 RAW Restoration & SR** (arXiv 2506.02197): includes a MambaIRv2-based efficient entry (table row "MambaIRv2 4.6 | Efficient | 40.32 | 0.9396 | 0.19"; column meanings not verified). — [arXiv 2506.02197](https://arxiv.org/html/2506.02197v2)
- **NTIRE 2024 Efficient SR**: DVMSR (Mamba + distillation) was a CVPRW 2024 NTIRE workshop paper. — [DVMSR README](https://github.com/nathan66666/DVMSR)
- **NTIRE 2025 Efficient SR** ("The Tenth NTIRE 2025 Efficient Super-Resolution Challenge Report", Bin Ren, Hang Guo, Lei Sun, Zongwei Wu, Radu Timofte, Yawei Li, CVPRW 2025, pp. 917–966, arXiv 2504.10686): 244 registrants, 43 valid teams; sub-tracks for runtime (RTX A6000), FLOPs and params. — [arXiv 2504.10686](https://arxiv.org/pdf/2504.10686); [dblp](https://dblp.org/rec/conf/cvpr/RenG0WT025.html). The **NTIRE 2026 Efficient SR** report is arXiv 2604.03198. — [arXiv 2604.03198](https://arxiv.org/pdf/2604.03198)
- Other NTIRE 2026 SR-adjacent reports: Mobile Real-World SR (arXiv 2604.17306) and Image Denoising (arXiv 2606.16031). — [2604.17306](https://arxiv.org/pdf/2604.17306); [2606.16031](https://arxiv.org/pdf/2606.16031)

### Inferences
- At NTIRE, the practical pattern is HAT (strongest single backbone) plus MambaIRv2 as a complementary branch or ensemble. Output-level fusion improving over the stronger branch suggests the two families make partly decorrelated errors. This is circumstantial evidence for complementarity, and consistent with LFTransMamba's choice in the LF track.
- Efficient-SR challenges (strict runtime) appear to have been dominated by CNN/re-parameterized designs, not Mamba, but I could not verify team-level architecture tables (see Gaps).

### Gaps
- Could not open the team tables of the NTIRE 2025/2026 ×4 or Efficient SR reports to count Mamba-based teams or get their exact ranks and PSNR. The GitHub challenge repos' READMEs (zhengchen1999/NTIRE2025_ImageSR_x4, NTIRE2026_ImageSR_x4, Amazingren/NTIRE2025_ESR, NTIRE2026_ESR) contain no "Mamba" mentions, and the repo tree API was blocked.
- No AIM 2024/2025 challenge evidence on Mamba was found in the time available.

## Q4. Efficiency in practice: params, FLOPs, runtime and memory of Mamba SR vs SwinIR/HAT/DAT/ATD-type Transformers

### Takeaway
Mamba SR models have fewer FLOPs than full-attention models at large inputs, but the evidence is mixed at typical SR patch sizes. Several papers blame immature SSM scan kernels and multi-direction scanning for slower-than-expected wall-clock speed. Window Transformers lose time to tensor permutation and window partitioning instead. Reported complexity numbers themselves need care: MambaIR's own `thop` counts were wrong.

### Cited Findings
- MambaIR's params/MACs were under-counted with `thop`. The fvcore-based count is larger than reported, and lightweight-SR comparisons were revised (arXiv v-Oct-2024). — [MambaIR README](https://github.com/csguoh/MambaIR)
- MAC comparison at ×2 light: MambaIR-light 905K / 334.2G vs SRFormer-light 853K / 236.3G. MambaIRv2-light 774K / 286.3G. MambaIRv2 has "slightly higher computational cost than SRFormer" with about 10% fewer params and better Urban100/Manga109 PSNR. — [search extracts of lightweight-SR tables, e.g. arXiv 2411.15269](https://arxiv.org/html/2411.15269v2); [T-PMambaSR](https://arxiv.org/pdf/2511.03232)
- **EchoSR** (arXiv 2605.17470, 2026): in its latency tests MambaIR is faster than SRFormer but "still slower than HiT-SIR; its real-world speed is currently limited by the early stage of SSM kernel optimizations". For SRFormer/HiT-SIR, "frequent high-dimensional tensor permutations and irregular window partitioning create severe data movement bottlenecks." — [arXiv 2605.17470](https://arxiv.org/html/2605.17470)
- **OmniRWKVSR** (arXiv 2502.00404): "MambaIR and its derivatives, such as SS2D and Attentive SSM, also exhibit linear complexity, [but] their computational efficiency does not match that of OmniRWKVSR... attributed to the less optimized CUDA operations". Timing on an A800: MambaIR training 4h32m and inference 21m12s; SwinIR inference about 25 min. — [arXiv 2502.00404](https://arxiv.org/html/2502.00404v1)
- **DVMSR** (CVPRW 2024): SwinIR is +0.23 dB but has about 2× the params and about 20× the inference time of the distilled Mamba model. — [arXiv 2405.03008](https://arxiv.org/html/2405.03008v2)
- **MambaOSR** (omnidirectional SR, Entropy 2025): as input size grows, SwinIR latency becomes about 3× MambaIR's. — [doi 10.3390/e27040446](https://doi.org/10.3390/e27040446)
- **LKMN** (arXiv 2508.11893): at 512×512 ×4, SRFormer-light takes about 998.5 ms vs SAFMN (CNN) at about 34.8 ms. "Self-Attention mechanism significantly degrades the inference speed". This shows how slow window-attention light models can be relative to CNNs. — [arXiv 2508.11893](https://arxiv.org/html/2508.11893)
- **Multi-direction scanning cost** is named as a key overhead. EAMamba: "computational complexity that scales with the number of scanning sequences", and its MHSSM cuts FLOPs 31–89%. Hi-Mamba: multi-direction scanning adds "significant computation", so it uses single-direction scans with alternation. MambaCSR: interleaving horizontal and vertical scans removes directional redundancy. MambaIRv2: one scan instead of four, giving −43% params and −50% FLOPs vs MambaIR. — [EAMamba README](https://github.com/daidaijr/EAMamba); [Hi-Mamba arXiv](https://arxiv.org/pdf/2410.10140); [MambaCSR README](https://github.com/renyulin-f/MambaCSR); [MambaIRv2](https://arxiv.org/html/2411.15269v2)
- **XYScanNet**: a third-party summary reports −56.61% training time and −46.18% inference memory vs MambaIR's VSSM. — [Pith](https://pith.science/paper/2412.10338) (third-party summary)
- **Edge deployment**: SSM-distilled hybrids run 1.17–3.4× faster than Restormer on a Snapdragon 8 Elite CPU (see Q2). — [arXiv 2605.02794](https://arxiv.org/abs/2605.02794)
- Size parity at the top end (third-party summary): MambaIR 20.6M vs HAT 20.8M, and Contrast 14.1M at nearly HAT-level PSNR. — [Pith](https://pith.science/paper/2501.13353)

### Inferences
- At typical SR training patch sizes (48–64 px LR) and the small 1D sequence lengths inside windowed or striped scans, linear vs quadratic complexity matters little. Kernel launch and scan overheads, data layout, and the number of scan directions dominate. So "linear complexity" does not guarantee a faster model. Speed advantages show up mainly at large test resolutions (MambaOSR) or against unoptimized window attention (SRFormer).
- For a competition, wall-clock and memory should be profiled directly on the target GPU. Treat published FLOPs for Mamba models with suspicion: SSM scans are often missed by `thop`/`fvcore` unless registered.

### Gaps
- No controlled, same-hardware runtime/memory table of MambaIR/MambaIRv2 vs SwinIR/HAT/DAT/ATD at classic-SR scale (e.g., 256×256 or DIV2K-val ×4) was retrievable. The MambaIRv2 and Hi-Mamba papers may contain one but could not be opened.
- No source found that directly benchmarks DAT or ATD against Mamba SR runtime.

## Q5. Known weaknesses of Mamba in low-level vision and proposed fixes

### Takeaway
Weaknesses consistently identified across 2024–2026 papers: (1) 2D→1D flattening breaks locality and continuity; (2) local pixel forgetting; (3) causal, one-directional dependence; (4) long-range decay in the recurrent state; (5) redundancy and cost of multi-direction scanning, including channel redundancy; (6) inconsistency between sequences unfolded in different ways; (7) weak fine-grained local or high-frequency features. Fixes fall into three families: locality-preserving scans, non-causal or attentive SSMs, and adding conv or window attention.

### Cited Findings
- Flattening breaks locality and continuity → stripe + S-shaped scan (MaIR NSS), slice-and-scan (XYScanNet), progressive halves/quadrants/octants split (PS-Mamba), local-window + sequential interleaving (MambaCSR), local + region SSMs (Hi-Mamba). — [MaIR](https://github.com/XLearning-SCU/2025-CVPR-MaIR); [XYScanNet](https://arxiv.org/html/2412.10338); [PS-Mamba](https://arxiv.org/pdf/2603.09171); [MambaCSR](https://github.com/renyulin-f/MambaCSR); [Hi-Mamba](https://arxiv.org/pdf/2410.10140)
- Local pixel forgetting → local conv in RSSB (MambaIR), depthwise convs (XYScanNet), all-around scanning (EAMamba). — [MambaIR](https://arxiv.org/html/2402.15648v3); [XYScanNet CVPRW](https://openaccess.thecvf.com/content/CVPR2025W/NTIRE/papers/Liu_XYScanNet_A_State_Space_Model_for_Single_Image_Deblurring_CVPRW_2025_paper.pdf); [EAMamba](https://github.com/daidaijr/EAMamba)
- Channel redundancy → channel attention (MambaIR). — [MambaIR](https://arxiv.org/html/2402.15648v3)
- Causal scanning → attentive state-space equation, non-causal "like ViTs" (MambaIRv2). Six-direction omni scan (VmambaIR). Bidirectional or multi-direction recurrence in the RWKV analog (Restore-RWKV Re-WKV). — [MambaIRv2](https://github.com/csguoh/MambaIR); [VmambaIR](https://github.com/AlphacatPlus/VmambaIR); [Restore-RWKV](https://arxiv.org/pdf/2407.11087)
- Long-range decay → semantic-guided neighboring, which reorders similar pixels adjacently (MambaIRv2), and cross-scale low-frequency shortcuts (PS-Mamba). — [MambaIRv2 CVPR](https://openaccess.thecvf.com/content/CVPR2025/papers/Guo_MambaIRv2_Attentive_State_Space_Restoration_CVPR_2025_paper.pdf); [PS-Mamba](https://arxiv.org/pdf/2603.09171)
- Sequence discrepancy across scan orders → Sequence Shuffle Attention for aggregation instead of summation (MaIR). — [MaIR](https://github.com/XLearning-SCU/2025-CVPR-MaIR)
- Multi-direction scanning cost → MHSSM (EAMamba), single-direction + alternation (Hi-Mamba), single scan (MambaIRv2), H/V interleaving (MambaCSR). — sources as in Q4.
- Lack of fine-grained local / high-frequency detail → frequency branches (FreqMamba, FMSR, FourierMamba), high-frequency refinement (T-PMambaSR AHFRM), texture-aware transition modulation (TAMambaIR). — [Awesome list](https://github.com/csguoh/Awesome-Mamba-in-Low-Level-Vision); [T-PMambaSR](https://arxiv.org/html/2511.03232v1); [Visual Mamba survey](https://arxiv.org/pdf/2404.18861)
- Mamba as gated linear attention (MLLA): the forget gate gives a positional or recency inductive bias, and the block design matters most. This frames "positional bias" as a property of the decay gate, not of explicit position embeddings. — [arXiv 2405.16605](https://arxiv.org/pdf/2405.16605)

### Inferences
- Scan-order fixes (MaIR, PS-Mamba, Hi-Mamba) and attention fixes (MambaIRv2, hybrids) attack the same issue from two sides: making sure spatially or semantically related pixels interact strongly. Window attention does this by construction, which is why hybrids reach the same goal with simpler scans.

### Gaps
- Found no paper that explicitly measures "positional bias" of Mamba scans in restoration (e.g., PSNR vs pixel position along the scan, or flip/rotation sensitivity). The closest evidence is the widespread use of multi-direction scans and self-ensemble (geometric TTA) in challenge entries.

## Q6. Surveys and meta-analyses on Mamba for low-level vision

### Takeaway
Several general vision-Mamba surveys (2024–2025) have low-level sections, there is one Chinese restoration-specific survey, and there is a 2025 comparative SR study. The most current curated inventory is the Awesome-Mamba-in-Low-Level-Vision list maintained by the MambaIR authors, updated through Sept 2026.
